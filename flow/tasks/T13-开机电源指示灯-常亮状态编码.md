# T13 · 开机电源指示灯（清醒时常亮，通道状态编码）

- 日期：2026-09-15 设计实现 / 2026-09-16 烧录真机确认；分支 `my-host-action-practice-v2`。
- 来源：使用者需求——纯电池开机（不插 USB）时整板无任何灯亮，无法判断是否已开机；希望开机清醒期间有一颗指示灯。
- 性质：课程 Host Action v1 之外的增量功能；只改 LED 平台层，不涉及 GPIO8/GPIO12、BOOT、分区、sdkconfig、USB/BLE 身份、HID/GATT 与 App 映射。

## 1. 原因分析（只读取证）

- GPIO8 共享电源轨在整个清醒期间本就使能（main/platform/peripheral_power.h 注释：DeviceAwake 持有到整板提交深度睡眠），灯不亮不是供电问题。
- 原 `StatusLedStrip::render_idle_status()`（main/platform/led_strip_status.cpp）固定 `set_all({})`——待机故意全灭；USB/BLE 连接只触发 0.4–0.9 秒一次性动画（sync_led_status, main/app_main.cpp:2287-2308），连接状态不保留为背景，动画结束回到全灭。
- `prepare_for_deep_sleep()` 已会刷一帧全黑（随后 GPIO8 拉低），指示灯走正常空闲渲染即可在睡眠时自动灭，无需电源改动。

## 2. 设计（使用者拍板）

中间第 3 颗（5 颗 WS2812 的中心）静态常亮，单帧、无周期刷新：

| 清醒状态 | 颜色（RGB） | 含义 |
|---|---|---|
| USB 在线（双连接时 USB 优先，与固件 USB-first 一致） | {5,5,5} 暗白 | 开机 + USB 通道 |
| 仅 BLE 在线 | {0,0,9} 暗蓝 | 开机 + BLE 通道 |
| 无任何主机（纯电池待机） | {2,2,2} 极暗白 | 仅表示已开机 |

- 按键反馈、连接动画、配置模式彩虹、Agent 状态灯效期间指示灯让位，效果结束自动恢复。
- 深度睡眠黑帧逻辑不变，睡眠即灭。
- 单颗低亮度 LED 约 0.3–0.5 mA。

## 3. 代码改动（2 个文件）

- main/platform/led_strip_status.h：`StatusLedStrip` 增加持续状态位 `usb_connected_`、`ble_connected_`（默认 false）。
- main/platform/led_strip_status.cpp：
  - `show_status_event()` 的 Usb/Ble Connected/Disconnected 四个分支更新状态位并置 `idle_rendered_=false` 触发背景重绘；原有一次性连接动画参数全部不变。
  - `render_idle_status()` 由全灭改为中心像素按上表着色后 `flush()`；其余渲染/冷启动/睡眠路径未改。

- 冷启动自检结束后，**中间第 3 颗保持微亮**（USB 连接，暗白）——符合预期。
- 系统枚举：正常模式 VID 0x303A/PID 0x1006 三 HID 集合、串口 0（无 CDC 符合设计）、PID1001 下载节点归零。
